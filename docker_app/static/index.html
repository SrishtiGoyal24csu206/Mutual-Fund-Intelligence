About MF Intelligence

Project Objective

Mutual Fund Intelligence is a data analytics and machine learning project designed to study mutual fund performance, investment risk, NAV trends, SIP inflows, investor behaviour and portfolio holdings.

Technologies Used

Python, Pandas and NumPy
Matplotlib and Chart.js
Scikit-learn and Joblib
FastAPI and HTML/CSS/JavaScript
Docker for application containerization
